# Imágenes de Fresas con Crema

Las imágenes usadas por `index.html` son locales y deben conservar estos nombres:

| Archivo | Uso |
| --- | --- |
| `logo.jpg` | Logo del encabezado |
| `nutella-500.jpg` | Tarjeta Nutella, presentación 500 ml |
| `nutella-350.jpg` | Tarjeta Nutella, presentación 350 ml |
| `leche-condensada-500.jpg` | Tarjeta Leche Condensada, presentación 500 ml |
| `leche-condensada-350.jpg` | Tarjeta Leche Condensada, presentación 350 ml |

El sitio cambia las presentaciones cada 10 segundos y actualiza la imagen y el enlace de pedido junto con la capacidad.

Nota de formato: la inspección de firma detectó que `nutella-350.jpg`, `nutella-500.jpg`, `leche-condensada-350.jpg` y `leche-condensada-500.jpg` contienen datos PNG pese a la extensión `.jpg`. Antes de publicar, convertí esos cuatro archivos a JPEG real conservando los nombres indicados. El logo sí es JPEG.
