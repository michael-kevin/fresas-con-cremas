# Imágenes del sitio

Las imágenes actuales todavía se cargan desde Unsplash. No hay archivos locales para migrar, por eso los `src` del HTML siguen apuntando a sus URL actuales hasta incorporar y comprobar las copias locales.

Cuando estén disponibles, guardá cada imagen con el nombre indicado y actualizá su `src` correspondiente en `index.html`:
